## Changelog
- August 2026 version 1.3.2: gave BLESerial-owned diagnostics a dedicated configurable `Print` output that defaults to `Serial`, accepts UART and application-provided outputs, and rejects the BLESerial transport itself. Application logging continues to follow global `logSetOutput()`, and `printStats(stream)` remains explicitly routed by the caller. Internal diagnostics now use explicit destination-aware dispatch, with a `selflog` text-stress command for regression coverage. Requires `UUtzinger_logger` 2.2.1 or newer.
- August 2026 version 1.3.1: made Arduino `write()`, `print()`, `println()`, and `printf()` use bounded reliable TX enqueueing, with explicit `writeNonBlocking()` and `printfNonBlocking()` APIs for high-rate streaming. Increased TX task stack capacity and corrected PHY/DLE pacing calculations. Made RSSI adaptation mode-specific and resistant to outliers by requiring three consecutive downgrade decisions, six upgrade decisions, hysteresis, and a post-change holdoff. Improved congestion recovery so isolated `ENOMEM` events return to the exact confirmed last-known-good pace. General congestion must persist for one second before escalation; high-water escalation requires at least eight events over 250 ms. Escalation remains gradual and capped, successful traffic restores probing, and repeated warnings are rate-limited. Separated DLE maximum TX time from estimated packet airtime in diagnostics. Added the deterministic text-stress example, comprehensive reset diagnostics, updated operation-mode documentation, and expanded hardware verification tasks.
- July 2026 version 1.3.0: corrected the MTU API with separate preferred and negotiated values (`setPreferredMTU()`, `getPreferredMTU()`); retained `requestMTU()` as a deprecated compatibility alias. Hardened RX/TX lifecycle handling, task-mode pacing and fallback behavior, callback ownership, logger-level preservation, and initialization cleanup. Added offline warning-enabled build validation.
- July 2026 version 1.2.1: switched BLESerial diagnostics to `UUtzinger_logger`.
- March 2026 version 1.2.0: added pairing policies and pairing window control; switched RingBuffer to external dependency `UUtzinger_RingBuffer`.
- November 2025 error handling of onStatus, buffer optimizations.
- November 2025 first release
